# 架构方案：粗线四边界生成部件 raw 框（抑幽灵）

- 版本：v4.0
- 日期：2026-08-14
- 用户确认：是（2026-08-14）
- 前序：v3.0（VLM Pass0 粗框 → 粗轮廓收紧）；本版为需求变更重启

## 需求概述

- **核心目标**
  1. **先识别图中粗线**（工程图 object line / 可见粗实线），不以 VLM 框为部件几何的第一来源。
  2. **以粗线为上下左右四边界**，生成部件 **raw 识别框**（贴粗边的 AABB）。
  3. 框须**精确贴合粗轮廓**，且**不出现幽灵框**（空白处假框、无粗线支撑的框、重复/漂移框）。
- **输入**：整页图纸图像；可选既有表格/图框先验；配置 `perception.view_regions`
- **输出**：`component.bbox`（raw，粗线四边界）；后续仍可走既有 `bbox_expanded` / 尺寸分区
- **约束**：不改尺寸 OBB / 数字重叠 OCR 主路径；技术栈 Python + OpenCV/numpy；VLM 可降级为可选标注/兜底，不得作为 raw 框的唯一依据

## 可行性结论

**可行**

- 工程图零件视图的可见轮廓线宽显著大于尺寸/剖面/中心细线；可用线宽筛选得到粗线掩膜。
- 闭合或近闭合的粗线轮廓可抽取外接四边界（min/max 外缘）形成 raw AABB。
- 幽灵框可通过「四边粗线证据 + 面积/空白比 + 与表格/图框冲突剔除 + 重叠抑制」在几何层过滤，不依赖 VLM 幻觉抑制。

## 与 v3.0 的差异（变更点）

| 项目 | v3.0 | v4.0（本方案） |
|------|------|----------------|
| raw 框来源 | VLM Pass0 → 再 `tighten` | **粗线检测 → 四边界成框**（几何优先） |
| VLM 角色 | 主定位 | **可选**：标签/二次确认/几何失败兜底 |
| 幽灵框治理 | 近全页面积丢弃等弱过滤 | **显式反幽灵闸门**（见 C3） |

## 模块划分

| 模块 | 职责 | 所需算法/逻辑/架构类型 |
|------|------|------------------------|
| C1 粗线提取 | 全页/ROI 内分离粗实线与细标注线 | 线宽/笔画形态学筛选（或等价笔画宽度变换类） |
| C2 四边界成框 | 由粗线连通结构生成候选 AABB（上下左右贴粗外缘） | 连通域/轮廓外接矩形 + 正交边界聚合 |
| C3 反幽灵闸门 | 剔除无四边支撑、空白漂移、重复、图框/表冲突的候选 | 规则引擎：边证据 + 密度/面积约束 + NMS/IoU 抑制 |
| C4 接入与回退 | 替换/前置 Pass0 raw 源；失败回退网格或可选 VLM | 管道编排 + 可配置 fallback |
| C5 缓存指纹 | 新参数变更使旧缓存失效 | 配置哈希 |

## 数据流与接口约定

```
页图
  → extract_thick_strokes(image, cfg) → thick_mask
  → propose_boxes_from_thick_boundaries(thick_mask, cfg) → raw_candidates[]
  → filter_ghost_boxes(raw_candidates, image, tables?, cfg) → component.bbox[]
  →（既有）expand_view_bbox → bbox_expanded / 尺寸区
  →（可选）VLM 仅补 label 或几何空结果时兜底
```

| 字段/配置（建议） | 含义 |
|-------------------|------|
| `view_regions.propose_mode` | `thick_boundary`（默认）\| `vlm_then_tighten`（兼容 v3） |
| `view_regions.thick_min_width` | 粗线最小笔画宽（px） |
| `view_regions.min_side_evidence` | 四边中至少几条须有粗线支撑（建议 3–4） |
| `view_regions.min_ink_density` / `max_empty_frac` | 框内粗线/墨迹密度下限，抑空白幽灵 |
| `view_regions.max_area_frac` | 过大框（近全页/图框）丢弃 |
| `view_regions.box_nms_iou` | 候选框重叠抑制 |
| `view_regions.exclude_tables` | 与已知表格 IoU/中心冲突则丢弃 |

接口约定（逻辑级，不绑具体函数名实现细节）：

- `extract_thick_strokes(image) → mask`：粗线二值掩膜
- `propose_from_thick(mask) → list[{bbox, score?}]`：每框四边由粗线外缘决定
- `filter_ghost(...) → list[bbox]`：只保留有证据、非幽灵的框

## 开发步骤与验收标准

| 步骤 | 描述 | 所需算法类型 | 验收标准（可测试） |
|------|------|--------------|---------------------|
| C1 | 粗线掩膜纯函数 | 线宽筛选类 | 合成图：粗矩形边保留、内部/外围细线被抑制；掩膜面积显著小于全墨迹 |
| C2 | 由粗线生成 raw AABB | 轮廓/连通域外接框 | 合成两分离粗矩形 → 恰好 2 个框，且四边误差 ≤ pad+1px；框不覆盖大片空白外延 |
| C3 | 反幽灵过滤 | 规则闸门 | ① 空白区无粗线支撑的假候选被丢弃；② 重复高 IoU 框合并/抑制为 1；③ 与表/图框冲突候选丢弃；④ 仅细线围成的区域不成框 |
| C4 | 接入 `locate`/部件实例路径 | 管道编排 | `propose_mode=thick_boundary` 时 raw 框来自 C2+C3；几何空结果可配置回退；notes 可观测来源 |
| C5 | 单测 + 冒烟 + 指纹 | 工程集成 | 相关 pytest 通过；指纹含 `propose_mode` 与反幽灵关键参数 |

## 风险与外部依赖

- **非矩形零件 / 倾斜视图**：AABB 仍贴粗外缘，但可能含内部空白；不在本版做旋转框（OBB 留给尺寸路径）。
- **图框粗线**：外图框线宽常与零件接近 → 须靠面积上限、页边距邻接、表格区排除抑制「全页幽灵框」。
- **扫描线宽不均**：过强开运算打断轮廓 → 允许 CLOSE 补缝；证据阈值可配「至少 3 边」以避免漏检。
- **复杂剖视多连通**：同一视图多段粗线需合并策略（同簇外接）与反幽灵之间的平衡，以单测锁定。
