# 架构方案：部件粗边框识别 + 扩展收紧

- 版本：v3.0
- 日期：2026-08-14
- 用户确认：是（指令：按照 skill 加强部件识别）
- 前序：v2.0 尺寸准确率 + 倾斜框

## 需求概述

- **核心目标**
  1. 加强部件/视图定位：识别框应贴合零件**粗轮廓边框**（工程图粗实线），减少把细尺寸线、剖面线、指引线算进部件几何。
  2. **扩展框收紧**：在仍能覆盖附近尺寸标注的前提下，降低 `expand_ratio`，减少部件区间互相吞并。
- **输入**：Pass0 VLM 粗框 + 页图；配置 `perception.view_regions`
- **输出**：更贴粗轮廓的 `component.bbox`；更紧的 `bbox_expanded` / 尺寸分区
- **约束**：不改数字重叠 OCR 超参；不改尺寸 OBB 主路径；技术栈保持 Python + OpenCV/numpy + 既有 VLM

## 可行性结论

**可行**

- 工程图粗实线线宽显著大于尺寸细线；可用形态学开运算保留粗笔画、抑制细线后，再求墨迹外接框。
- 扩展比例为纯配置/几何缩放，可独立调小并做单测。

## 模块划分

| 模块 | 职责 | 所需算法/逻辑/架构类型 |
|------|------|------------------------|
| Pass0 提示强化 | 引导 VLM 以粗轮廓外缘为框 | 提示工程 / 约束描述 |
| 粗轮廓收紧 | 在粗框内滤细线、按粗边框贴边 | 形态学线宽筛选 + 外接矩形 |
| 扩展收紧 | 降低外扩比例 | 可配置几何外扩 |
| 缓存指纹 | 新参数变更失效旧缓存 | 配置哈希 |

## 数据流与接口约定

```
VLM Pass0 粗框
  → tighten_to_thick_outline(image, bbox, cfg) → component.bbox（贴粗边）
  → expand_view_bbox(..., expand_ratio↓) → bbox_expanded / 尺寸区
```

| 字段/配置 | 含义 |
|-----------|------|
| `view_regions.tighten_mode` | `ink`（旧全墨迹）\| `thick_outline`（默认粗边） |
| `view_regions.thick_min_width` | 视为「粗线」的最小笔画宽度（px） |
| `view_regions.expand_ratio` | 外扩比例（默认下调） |

## 开发步骤与验收标准

| 步骤 | 描述 | 所需算法类型 | 验收标准 |
|------|------|--------------|----------|
| B1 | 粗轮廓收紧纯函数 | 形态学线宽筛选 + AABB | 粗矩形框+内部细线噪声时，收紧结果贴近粗框，不被外围细线撑大；比全墨迹更贴粗边 |
| B2 | Pass0 接入 + 提示 | 提示工程 | locate 路径调用粗轮廓收紧；notes 可观测 |
| B3 | 扩展比下调 | 配置 | 默认 `expand_ratio` 小于原 0.28；expand 单测覆盖 |
| B4 | 单测+冒烟+缓存指纹 | 工程集成 | pytest 通过；指纹含新参数 |

## 风险与外部依赖

- 扫描件线宽不均匀时，过强开运算可能打断轮廓 → 需 CLOSE 补缝 + 失败回退全墨迹收紧。
- 扩展过紧可能漏掉贴边尺寸 → 保留 `fill_uncovered_grid` 补扫。
